# PHP Authentication System

A simple authentication system built with PHP and MySQL.  
This project was created as a practice/demo project to implement the basic concepts of authentication, session management, and user account handling in plain PHP.

## Features

- User registration
- User login
- User logout
- Session-based authentication
- Basic form validation
- Protected pages for authenticated users only

## Technologies Used

- PHP
- MySQL
- HTML / CSS
- XAMPP / Laragon / LAMP (for local development)
